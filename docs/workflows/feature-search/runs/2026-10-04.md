## Protocol and result

- Generated 15 independent datasets, each from a separate seed, with 120 simulator runs. Training used normal-only runs; validation held labeled normal/anomaly runs. Each dataset also has 18 reserved test runs, never loaded by this search.
- Screened 16 configurations with three seeds each: full baseline, continuous signal-class ablations, and four feature-family ablations.
- Compared five selected ablations and the baseline on the same 12 additional datasets with paired per-dataset seeds: 72 finalist/control trainings. Together with 48 screening trainings this is 120 successful trainings, zero failed. Autoencoder training used 30,000 configured steps per run; Isolation Forest was trained for every run.
- Best mean-rank ablation was `Sin signal_class: rotational_speed`: PR-AUC 0.1778 ± 0.0639 versus baseline 0.1684 ± 0.0648. Paired PR-AUC difference was +0.0094, 95% CI [-0.0088, +0.0276], inconclusive.
- `Sin signal_class: feed_rate` reduced false positives by 7.61 per asset-day on average (95% CI [-14.17, -1.05]), while its event-detection change was -0.0049 (95% CI [-0.0517, +0.0420]); its PR-AUC was effectively unchanged. This is a possible operating trade-off, not a general improvement.
- Removing vibration reduced event detection by 0.0338 (95% CI [-0.0574, -0.0102]) and reduced false positives by 8.74/day (95% CI [-15.96, -1.52]); evidence suggests a sensitivity/alert-volume trade-off in this generator.
- Across models, event-detection rate remained low (roughly 3.3%-7.6%) and variable. The results do not validate event detection on field data.

## Corrections during execution

An initial partial run was stopped before selection when review found that candidate seeds were not paired. A subsequent smoke run exposed a Windows atomic-replace collision. The runner was corrected to pair seeds and use unique retrying atomic state writes; neither partial run contributes to the reported results. The 12-run paired baseline control was then added to the completed finalist experiment before analysis.

## Limits

This is a single pseudo-synthetic generator, one 1-minute window/stride configuration, fixed 0.95 decision operating point and 12 paired holdout seeds. Mean metrics hide per-seed range (full paired data retained); the Student t interval assumes seed-level differences are sufficiently well behaved and is descriptive at this sample size. The screening-selected candidates share selection bias. No threshold optimization, feature-by-feature exhaustive search, different simulator, open industrial dataset, or reserved test evaluation was performed. No field performance claim follows.
