# OT Irregularity Lab pseudo-synthetic benchmark

## Source and preparation

This benchmark adapts the [OT Irregularity Training Dataset v0.3.0](https://github.com/Mysthrala-Kurogane-Defense-Labs/ot-irregularity-lab/releases/tag/dataset-v0.3.0), generated by the independent OT Irregularity Lab. The source release is CC BY 4.0. It contains 1,000 independent simulation runs and 8,477,689 telemetry observations, with 700/150/150 run partitions and separate per-run ground truth. Its simulator version is 0.3.0 and telemetry schema is 1.0.0.

The source suite mixes normal and event-bearing runs, so it must not be fed directly to this repository's unsupervised trainer as normal data. `scripts/prepare_otlab.py` verifies source telemetry hashes and licensing metadata, selects only runs with no ground-truth events from source `train/` and `validation/`, and adds event interval labels only to the disjoint source `test/` partition. Event IDs are namespaced by run because the source uses IDs local to each run. For event intervals with no surviving observation (such as complete communication loss), evaluation metadata is anchored to the nearest surviving observation so overlapping windows are still labeled. Labels are evaluation-only; event types, run IDs, and asset IDs are excluded from model features. The adapted dataset and trained artifacts stay outside Git.

Example preparation and use:

```powershell
uv run python scripts/prepare_otlab.py `
  --source $OT_LAB_CHECKOUT\datasets\ot-irregularity-training-v0.3-release `
  --output $OT_IRREGULARITY_LOCAL\otlab-v0.3

uv run ot-irregularity train `
  --dataset $OT_IRREGULARITY_LOCAL\otlab-v0.3 `
  --config configs/benchmark-otlab.yaml `
  --output $OT_IRREGULARITY_LOCAL\model-otlab-v0.3

uv run ot-irregularity evaluate `
  --model $OT_IRREGULARITY_LOCAL\model-otlab-v0.3 `
  --dataset $OT_IRREGULARITY_LOCAL\otlab-v0.3\test

uv run ot-irregularity infer `
  --model $OT_IRREGULARITY_LOCAL\model-otlab-v0.3 `
  --dataset $OT_IRREGULARITY_LOCAL\otlab-v0.3\test `
  --output $OT_IRREGULARITY_LOCAL\otlab-v0.3-predictions.jsonl
```

The 5-minute windows fit the source runs, which last 5–10 minutes. Whole runs remain disjoint across partitions. The benchmark configuration keeps the 50/50 ensemble only as the existing tunable baseline; it does not assert optimal weights.

## Interpretation

This evaluates whether the detector can learn event-free operating variation from one simulation suite and rank event-bearing or normal test windows from other runs in that same simulator family. It is useful for end-to-end pipeline checks, controlled anomaly-family coverage, and false-positive stress within generated regimes. It is not a field-performance estimate, an industrial incident prior, or evidence of transfer to a physical plant or unrelated simulator. The lab's process models are simplified and not calibrated as digital twins. The test partition's generated event prevalence is a benchmark choice.

The original release is CC BY 4.0. The local adapted data records attribution and changes in `DATASET_LICENSE.txt`; retain those notices when redistributing it. Software in this repository remains Apache-2.0. Model weights and downstream redistribution should preserve the dataset attribution and license context.

## Results

The held-out test partition has 150 runs (51 normal, 99 event-bearing), 1,380,342 observations and 144 ground-truth events. Model training uses 246 event-free train runs (1,987,561 observations) and 62 event-free validation runs (456,845 observations). The base seed is 42, the scaler is RobustScaler, and the 50/50 score blend is the existing configurable baseline.

At 5m this yields 1,839 training windows and 457 normal validation/calibration windows; at 1m it yields 3,727 training and 917 normal validation/calibration windows. Ten of the 144 source events do not intersect a complete 5m inference window; all events intersect a 1m window.

| Window | Detector | PR-AUC | ROC-AUC | Precision at 0.95 | Recall at 0.95 | FP / asset-day | Event detection |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 5m | Autoencoder | 0.322 | 0.473 | 0.325 | 0.097 | 94.14 | 16/134 (0.119) |
| 5m | Isolation Forest | 0.336 | 0.496 | 0.372 | 0.087 | 68.57 | 19/134 (0.142) |
| 5m | 50/50 ensemble | 0.328 | 0.482 | 0.387 | 0.060 | 44.16 | 11/134 (0.082) |
| 1m | Autoencoder | 0.133 | 0.499 | 0.163 | 0.067 | 60.22 | 19/144 (0.132) |
| 1m | Isolation Forest | 0.139 | 0.531 | 0.201 | 0.110 | 76.59 | 27/144 (0.188) |
| 1m | 50/50 ensemble | 0.138 | 0.516 | 0.191 | 0.057 | 42.10 | 16/144 (0.111) |

An additional event-free transition stress test was generated with the Lab's `normal-operation-v0.1` suite: 120 new runs, seed 20261007, simulator v0.3.1, with varied startup/shutdown, load shifts, ambient drift, cadence and jitter. Its separate `test/` partition has 18 runs, 264,337 observations and no injected events. The adapted suite copy explicitly declared CC BY 4.0. On those normal windows at the same 0.95 threshold:

| Window | Detector | Normal windows | False-positive windows | FP / asset-day |
| --- | --- | ---: | ---: | ---: |
| 5m | Autoencoder | 456 | 48 | 151.58 |
| 5m | Isolation Forest | 456 | 119 | 375.79 |
| 5m | 50/50 ensemble | 456 | 45 | 142.11 |
| 1m | Autoencoder | 604 | 22 | 52.45 |
| 1m | Isolation Forest | 604 | 40 | 95.36 |
| 1m | 50/50 ensemble | 604 | 10 | 23.84 |

At 5m, 401/1,239 windows (32.4%) are positive; the ensemble PR-AUC of 0.328 is nearly the prevalence baseline. At 1m, 299/2,463 windows (12.1%) are positive; the Isolation Forest PR-AUC is only modestly above prevalence and ROC-AUC remains near 0.5. The 0.95 threshold yields too many false positives and detects few events. On the separate normal-transition stress set, the 1m ensemble gives 23.84 false positives per asset-day versus 142.11 at 5m. On the event-bearing test partition, the 1m ensemble has lower point recall (0.057 vs 0.060) but higher event coverage (0.111 vs 0.082). This supports 1m as an experiment candidate for further held-out evaluation; it does not validate a production setting. Window comparison used the same released event-bearing test set and is exploratory, not independent model or threshold selection.

The exact training, evaluation, and repeat-inference evidence is in [`docs/workflows/otlab-pseudosynthetic/runs/2026-10-03.md`](workflows/otlab-pseudosynthetic/runs/2026-10-03.md). These results are not comparable to Petrobras 3W metrics: the source family, run duration, channel set, event definitions, and prevalence differ.
