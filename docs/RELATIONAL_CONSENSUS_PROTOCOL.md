# Fixed relational consensus development protocol

Declared after the corrected telemetry-health study, before evaluating a combined decision. Normal-development overlap shows many seed-specific false windows, but does not establish event retention. This is adaptive development, not an independent validation claim.

## Fixed candidate

Use the three frozen original relational seeds 20261005/6/7, each with its original threshold and baseline maximum. Define each margin as `original_score / original_threshold`. Use the median of the three margins: a majority decision at margin >=1. Supplement with the corrected quality/availability channel at .05, repetition disabled. Combined margin is `max(median_margin, health/.05)`; ranking is `margin/(1+margin)`, threshold .5, not a probability. Missing health remains explicitly unavailable and contributes no positive alert; all three model members must be present and finite. Preserve component scores and member decisions.

No additional fit, calibration, seed selection, threshold search or architecture change. Report unanimity and union only as descriptive comparators, never alternative selectable candidates in this protocol. They use minimum and maximum margins respectively. Models, health reference, configured-cadence contract and source hashes must remain frozen. Verify saved member scores against fresh inference and reload the health reference on verified extracted caches before evaluation.

## Development gate

Use the same 1,965 historical mixed and 7,864 new normal-development windows, with exact window identity checks. No consumed test/challenge data. The candidate must preserve every baseline-detected nonphysical event and every physical event detected by the primary **corrected health** control. Total event detections >= that primary corrected control (86/124), historical false windows <= baseline (4), precision >=.5. New normal false windows <= primary corrected control (25) and <=10/asset-day in every class. Report exact events lost from each member, family counts, PR-AUC, recall, latency, normal strata and component availability.

Only the fixed majority can pass. If it fails, retain all results and consume no new holdout. If it passes, freeze this exact three-member ensemble and health reference before generating independent mixed and normal confirmation data. Three seeds in one ensemble are not three independent replications of the ensemble; label this limitation and assess fresh-data performance before promotion. Generalization to unseen industrial sources and thermal deficiencies remain separate requirements toward v1.0.
