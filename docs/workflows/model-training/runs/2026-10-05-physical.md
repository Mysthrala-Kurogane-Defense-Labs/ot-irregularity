## Reproduction

Paths below are local artifact arguments, not private dependencies. The baseline is the frozen primary v0.4 model. `$RawDevelopment` contains `raw-01` through `raw-15` from the historical paired feature study; `$Dataset` is their normalized train/validation assembly.

```powershell
$env:CUBLAS_WORKSPACE_CONFIG = ':4096:8'
uv run python scripts/research_physical.py --dataset $Dataset --baseline $Baseline --raw-root $RawDevelopment --output $Research --device cuda:0
uv run python scripts/validate_physical.py freeze --baseline $Baseline --research $Research --output $Validation
# In the pinned Lab checkout, repeat for seeds 910512 and 910513:
uv run ot-lab dataset create --suite suites/training-v0.2.yaml --runs 240 --seed 910511 --workers 4 --output $Raw1
# Back in the detector checkout:
uv run python scripts/validate_physical.py evaluate --baseline $Baseline --research $Research --output $Validation --sources $Raw1 $Raw2 $Raw3 --device cuda:0
uv run pytest -q
```

Output directories must be fresh. Existing evaluations are not overwritten. Checkpoints/data/predictions remain outside Git. The scripts expose JSON progress via the existing feature-search server.
