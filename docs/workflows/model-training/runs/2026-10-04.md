## Learnings applied and implementation follow-up

- Kept all continuous roles; an ablation rank alone was not treated as an improvement. Vibration stayed because its removal materially reduced event detection. Categorical state/code inputs stay out until modeled explicitly.
- Fit exclusively on event-free training behavior; calibration references only normal validation windows; test labels are evaluation only.
- Used RobustScaler, CUDA, paired-search-derived semantics and persisted scores from both detectors plus ensemble.
- Added generic configurable `model_version` metadata/output support. The final `training_progress.jsonl` completion event was corrected to match model metadata after an older hardcoded event label was noticed; the trained tensors and evaluation are unaffected.
- Added `scripts/assemble_feature_search_dataset.py` with license/schema/normal-only/disjoint-run checks and run/event namespacing. Added a unit test for assembly.
- Final verification after all code changes: 26 tests passed; Python compileall and JavaScript syntax check passed. Artifact checksums and version/progress metadata assertions passed.

## Limitations

This is pseudo-synthetic data from one simulator only, fixed 1m windows and one operating threshold. Metrics can shift with event prevalence and simulator behavior. No industrial dataset was used, no asset-specific calibration occurred, and no causal diagnostic claim follows. The model is a local candidate, not a public release.
